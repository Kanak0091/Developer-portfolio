## Six-Semester Plan

### Semester 1 (Current) — Foundations
- **Core Skills & Subjects:** Python programming fundamentals, web development basics, data handling & visualization, computer science fundamentals, mathematics, everyday communications, and Linux terminal / Git workflows.
- **Projects:** `Developer-portfolio` index & GitHub Pages site, CSE103 Lab repository, and `Dscapstone` data workflow.
- **Certifications & Platforms:** HackerRank Python (Basic), LeetCode (`KC_009`), HackerRank (`kanakc0207`), and freeCodeCamp (`kanak0091`).
- **Weekly Habit:** Dedicated weekly self-study and coding practice beyond scheduled classes.

### Semester 2 — Core Computer Science
- **Core Skills:** Data structures (arrays, linked lists, stacks, queues, trees), problem-solving patterns, and object-oriented programming in Python.
- **Projects:** Data structures implementation repository with clear documentation and test cases.
- **Certifications & Platforms:** Python & DSA problem-solving milestones on LeetCode and HackerRank.

### Semester 3 — Intermediate
- **Core Skills:** Relational databases, SQL queries, joins, data modeling, and front-end web development (HTML, CSS, JavaScript).
- **Projects:** Database-backed application combining Python and SQLite/SQL.
- **Certifications & Platforms:** SQL practice track and responsive web development milestones.

### Semester 4 — Intermediate-Advanced
- **Core Skills:** Backend/web application development, REST APIs, data analysis workflows, and software engineering practices.
- **Projects:** Full-stack or data analytics web application with clean repository structure and documentation.
- **Certifications & Platforms:** Intermediate problem-solving and cloud/data fundamentals.

### Semester 5 — Specialisation (Track B: Data Science & AI / ML)
- **Core Skills:** Data manipulation, exploratory data analysis, statistical analysis, machine learning workflows, and interactive dashboards.
- **Projects:** Two domain-focused data/AI/telemetry projects with reproducible notebooks/code and documentation; target summer internship opportunities.
- **Certifications & Platforms:** Track-relevant data science / ML / analytics credentials and datasets/competitions practice.

### Semester 6 — Industry Ready
- **Core Skills:** End-to-end engineering, technical communication, code review, and interview readiness.
- **Projects:** Capstone project with faculty or industry guidance and polished portfolio repositories.
- **Certifications & Platforms:** Consolidated coding platform problem count and technical interview preparation toward internship/entry-level roles.
